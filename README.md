# 🗺️ Інтерактивний посібник картографа-початківця v2.0 (AutoCAD Civil 3D)

Сучасний, адаптивний інтерактивний веб-сайт документації та чеклістів для GIS-відділу з обробки хмар точок у **AutoCAD Civil 3D 2026** (стандарти Mappit / MAVAT, координати Israel TM Grid WKID 2039).

Сайт повністю статичний (HTML5, CSS3, ES6 JavaScript) без сторонніх залежностей чи збирачів, оптимізований для розгортання на **GitHub Pages** в один клік.

---

## 🚀 Як опублікувати на GitHub Pages

### Варіант 1. Через командний рядок (Git)

1. Відкрийте термінал у папці проєкту:
   ```bash
   cd C:\Users\petrr\.gemini\antigravity\scratch\cartographer-handbook
   ```

2. Ініціалізуйте репозиторій та зробіть перший коміт:
   ```bash
   git init
   git add .
   git commit -m "feat: release cartographer handbook with interactive tests"
   ```

3. Створіть новий публічний репозиторій на [GitHub](https://github.com/new) (наприклад, `cartographer-handbook`).

4. Додайте посилання на ваш репозиторій та завантажте файли:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/cartographer-handbook.git
   git push -u origin main
   ```

### Варіант 2. Без Git (прямо через сайт GitHub)

1. Створіть новий репозиторій на [github.com/new](https://github.com/new) (зробіть його **Public**).
2. На сторінці нового репозиторію натисніть **uploading an existing file** (або перетягніть файли).
3. Перетягніть із теки `C:\Users\petrr\.gemini\antigravity\scratch\cartographer-handbook`:
   - `index.html`
   - `README.md`
   - теку `css`
   - теку `js`
4. Натисніть кнопку **Commit changes**.

### Активація GitHub Pages

1. У репозиторії перейдіть у вкладку **Settings** &rarr; розділ **Pages** (зліва).
2. У блоці **Build and deployment &rarr; Branch** виберіть `main` і теку `/ (root)`.
3. Натисніть **Save**.
4. Через 1–2 хвилини сайт буде доступний онлайн за адресою:
   `https://YOUR_USERNAME.github.io/cartographer-handbook/`

## ✨ Ключові можливості сайту

- 🧪 **Інтерактивні тести знань (18 питань)**:
  - Питання охоплюють усі 11 розділів інструкції v2.0 (OSNAPZ, ΔZ, Mappit, REG/DIS, іврит, бровки, дедлайни).
  - **Неправильні відповіді миттєво підсвічуються червоним** із детальним обґрунтуванням помилки.
  - **Правильні відповіді підсвічуються зеленим** із посиланням на конкретний розділ інструкції.
  - **Живе табло (Scoreboard)** з круговим лічильником загального відсотка успішності, лічильниками відповідей та фільтрами (*Лише червоні помилки*, *Невирішені*).
- 🔍 **Живий пошук та фільтри**: швидкий пошук по тексту (клавіша `/`), фільтрація за критичними правилами, чекпоінтами, калькуляторами та шаблонами.
- 🧮 **Інтерактивний калькулятор ΔZ**: автоматичний розрахунок середнього зміщення та розкиду між точками; сигналізує про деформацію, якщо розкид перевищує 5 см.
- 📐 **Калькулятор масштабу та горизонталей**: динамічний розрахунок кроку горизонталей (Minor/Major), висоти шрифту та формату аркуша за формулою `масштаб ÷ 1000`.
- 📋 **Повний інтерактивний чекліст (Розділ 10)**: зберігає прогрес у `localStorage`, показує відсоток готовності та має функцію копіювання звіту перевірки для старшого картографа.
- ✉️ **1-Click Copy шаблонів листів**: готові англомовні шаблони А, Б, В для комунікації із замовником.
- 🔤 **Тестер шрифтів івриту**: наочне порівняння та попередження про підміну літер `א` / `ט`.
- 🌓 **Темна та світла теми**: автоматична підтримка системної теми або ручне перемикання з пам'яттю вибору.
- 📱 **Мобільна адаптивність та друк**: оптимізовано під смартфони, планшети та друк у PDF.
